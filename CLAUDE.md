# Claude Project Notes

## Project Context

This is a hackathon project. Prioritize fast, working iterations over broad refactors.

## Working Style

- Keep changes focused on the requested feature or bug.
- Prefer simple, readable code that teammates can understand quickly.
- Match the existing stack, file structure, naming, and formatting.
- Do not rewrite unrelated code during feature work.
- Add short comments only when the code would otherwise be hard to understand.

## Git Safety

- Check `git status` before making changes.
- Do not discard or overwrite teammates' work.
- If there are merge conflicts, authentication issues, or unexpected git state, stop and ask the project owner to resolve it.
- Use clear commit messages that describe the user-facing change.

## Before Finishing

- Run the most relevant tests, lint, build, or smoke check available in the repo.
- If no verification command exists yet, explain what was manually checked.
- Mention any unfinished assumptions or follow-up work clearly.
